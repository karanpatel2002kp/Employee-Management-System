
# Employee Management System

A beginner-friendly Employee Management System built using Python and Object-Oriented Programming (OOP).

## Features

- Add new employees
- Display all employees
- Update employee salary
- Search employees by ID
- Check salary status
- Delete employees
- Menu-driven interface

## Technologies Used

- Python
- Object-Oriented Programming
- Lists
- Functions
- Loops and Conditional Statements

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python employee_management.py
```

## Concepts Learned

- Classes and Objects
- Constructor (`__init__`)
- `self` keyword
- List of Objects
- Functions
- For and While Loops
- Conditional Statements
- Return and Break
